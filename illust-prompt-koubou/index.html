10仕上げの注意

ここは自由記述なので、清書後に「書かれているか」は見ますが、意味までは自動で確かめられません。描かせたくない物は下の欄へ。

ここに書いた物は、清書の結果に「否定の形（no car など）以外で出てこないか」を自動で検査します。Midjourney では --no に入ります（編集元の画像があるときは、--no を使わず「remove any …」と指示文に入れます）。英単語で書いてください（例：車 → car、スマホ → smartphone）。

清書・短縮のときに守らせる度合い

ChatGPT などで清書するとき、文字数が足りなければ「なるべく」から省かれます。「必須」は省かれず、清書後に入っているかを自動で検査します。「おまかせ」は清書に渡しません。

初めはオフです。オンにすると、文字の入力と選択だけをこの端末のブラウザ内に保存します（どこにも送信しません）。参考画像と分析結果は保存されないので、ページを閉じたら入れ直してください。共用のパソコンではオフのまま使ってください。

                AIうまくいく順番・書き方文字・参考画像
                ChatGPT最初に「何に使う、どんな絵か」を示し、背景・場面 → 主題 → 細部 → 制約の順に、見出しで区切って書く（OpenAIの公式ガイド）。文字は " " で囲み、ほかの文字を入れないと明記。参考画像は番号と役割をつけて渡す。
                Geminiキーワードの羅列ではなく文章で。主題 → 動作 → 場所 → 構図 → 画風。参考画像があるときは、最初に「この画像を〜として使い」と役割を書く（Googleの公式ガイド）。「〜なし」より「〜だけ」。文字や図解が多いときは Pro（思考モード）が正確。
                Grok1枚の写真を描写するように4〜6文で。主役 → 細部・数・角度 → 色面と小物 → 光 → 色（主役と背景を分けて）→ 切り取り（xAIの公式ガイド）。避けたいものを長く並べない。直すときは「変える所」を先に、最後に1文で「残す所」。
                Copilot「〜の画像を作って」と依頼の形で始め、主題・画風・光・構図を具体的に。詳しく書くほど従う。文字は " " で囲む。チャットで続けて直せる。
                Midjourney主題をいちばん前に置き、短く具体的に。設定（比率・除外など）は --ar --no などのパラメーターで最後に。約1,000文字を超えると自動で縮められる。日本語は苦手なので、ChatGPT などで清書してから使う。標準の V8.2 では、参照画像（最大4枚）を入力欄にドラッグして使う。オムニ参照は V7 専用。文字は短い英語なら可。
                Adobe Firefly画像の種類 → 主題 → 動作 → アングル → 光 → 背景 → 色 → 画風の順（Adobeの公式ガイドの8要素）。上限は約1,000文字。参考画像は「構図」と「スタイル」の2つの欄。人物の顔をそのまま写す機能はない。
                Ideogram画像の種類・画風 → 主題 → 場所 → 文字とその置き場所 → レイアウト → 色。マジックプロンプトはオフに。英字の文字入れが得意。日本語は崩れやすい。文字は1つ5〜7語までに。

                参考画像は「何を読み取るか」を決めてから渡す

                「これを参考にして」だけでは、AIは画像の何を使えばいいか分からず、背景や照明まで真似したり、逆に大事な顔立ちを無視したりします。このアプリでは、画像ごとに次の3つを用途・画風・使うAIに合わせて組み立てます。

                • 読み取るもの：例）人物の参考なら、顔の形・目・髪型・髪色・服の色
                • 捨てるもの：例）写真の背景・照明・画質・ポーズ
                • 描き直し方：例）写真の人物を「アニメ調」で描くなら、特徴を残したままアニメの描き方に置き換える

                色・明るさ・彩度・背景が無地かどうかは工房が自動で測り、数値（色コードなど）としてプロンプトに入れます。顔立ち・服装・ポーズなどの中身は、「② 参考画像」タブで ChatGPT・Gemini などに分析させ、その英文を貼り戻します。

                文字数の上限があるAI・日本語が苦手なAIは「清書」してから

                Midjourney・Firefly・Ideogram は、日本語を正しく読めず、文字数にも上限があります。工房は、入力した内容を「必須」「できれば」に分けた仕様書にまとめ、ChatGPT などに清書を頼む依頼文を作ります。日本語の部分は一語ずつ訳すのではなく、「どんな絵か」を読み取ってから英語にするよう指示しています。返ってきた答えを貼ると、文字数・日本語の残り・入れる文字・パラメーターを自動で検査し、合格したものだけを完成版としてコピーできます。

                思いどおりにならないときのチェックリスト

                • 形容詞より、目に見える特徴：「おしゃれな部屋」→「白い壁、木の床、観葉植物、窓から差す朝日」
                • 「高画質」「傑作」などの決まり文句は不要：最近のモデルは材質・光・色の具体的な描写に反応します。
                • 人物は2〜3人までが安全：多いほど服装や表情の取り違えが起きます。
                • 文字は短く：1行15文字程度まで。確実にしたいときは「文字は後で入れる」。
                • 直すときは一度に1〜2点：「③生成後の手直し」タブを使います。
                • 同じキャラで何枚も：1枚目の絵を参考画像（人物の見た目を保つ）として添付します。
                • 実在の人物の写真や他人の作品を参考にするときは、権利や肖像の扱いに注意してください。
